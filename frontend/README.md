# Interfaz AquaInsight

Interfaz React/Vite del proyecto académico de calidad del agua. Instalación, ejecución, pruebas y límites de uso en el [README principal](../README.md). Los perfiles se cargan desde la API; no se duplican en el frontend.

`npm ci`, `npm run dev` (puerto 3000), `npm test`, `npm run lint` y `npm run build`. El build se sirve desde FastAPI en el puerto 8000.
